JFrog has introduced Model Context Protocol (MCP) capabilities enabling developers to spin up self-service trials using AI agents like Cursor and Claude without manual intervention. The integration allows users to manage repositories, security scans, and platform operations through natural language commands directly in their development environment, streamlining the evaluation experience. Runy Rapaport, VP Product Led Growth, describes how the system automates environment setup and governance checks that previously required human configuration steps.
